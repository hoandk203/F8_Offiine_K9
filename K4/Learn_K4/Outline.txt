
Day42:functional component, useState, useEffect
- useState[state, setState]= useState():
+ Lưu giá trị cuối cùng của biến kể cả khi re-render
+ Không cập nhật state ngay khi logic thay đổi state được thực hiện
+ Khi state thay đổi thì component re-render

- useEffect(()=> , dependencies): Xử lý các công việc Side Effect ( việc bên lề, sau khi update UI)
+ Luồng: 1. State thay đổi -> 2. Re-render -> 3. UI update -> Callback trong useEffect hoạt động (nếu thỏa mãn điều kiện dependencies)

+ dependencies xảy ra các trường hợp:
1. null hoặc undefined -> mỗi lần component re-render callback sẽ chạy
2. [] -> component render lần đầu tiên callback sẽ chạy (chỉ chạy lần dầu)
3. [var1, var2,...] -> 1 trong các biến trong dependencies thay đổi callback sẽ chạy

+ Đặc biệt:
1. return một function trong useEffect với dependencies là [] thì logic trong function đó là Unmount
useEffect(()=>{
    return ()=>{
        console.log("unmount")
    }
}, [])
2. return một function trong useEffect với dependencies là [var1...] logic trong function đó là cleanup (nó sẽ cleanup của lần trước, rồi chạy logic trong useEffect của lần này sau)
useEffect(()=>{
    console.log("effect" + count);
    return ()=>{
        console.log("cleanup" + count)
    }
}, [count])

- useMemo(()=> , []): cache giá trị để không tính toán lại khi re-render (chỉ tính toán lại khi dependencies thay đổi)

- useCallback(()=> , []): cache một hàm để không khởi tạo lại hàm khi re-render (chỉ khởi tạo lại hàm đó khi dependencies thay đổi)
